# Security policy

This repository is a portfolio case study. It contains written documentation
and screenshots — no application source and no running code — so it has no
exploitable surface of its own.

## Reporting

If you believe something in this repository exposes sensitive information — a
secret committed to history, or identifying data visible in a screenshot —
please report it privately instead of opening a public issue. Reach me through
[danielbrosed.com](https://danielbrosed.com).

For security issues in the **live CeSeA Agenc.ia website**, contact the agency
through [ceseagencia.com](https://ceseagencia.com).

Valid reports are acknowledged and credited.
